# Reliable Edition 优化说明

本文档记录相对上游 `luoluoluo22/jianying-editor-skill` v1.7.0 的主要改动、原因和验收边界。

## 1. 草稿生命周期安全

- `JyProject(..., overwrite=False)` 改为默认行为。
- 已有草稿在未显式覆盖时仅加载，加载失败不会删除重建。
- 显式 `overwrite=True` 时，原草稿先移入带时间戳的备份目录。
- 备份失败时停止重建，不继续破坏性操作。

## 2. 只读环境诊断

- `scripts/doctor.py` 检查 Python、锁定依赖、FFmpeg/FFprobe、Playwright 当前版本所需的 Chromium 可执行文件、剪映安装与草稿路径。
- `api_validator.py` 默认转为只读诊断。
- 只有显式传入 `--smoke` 时才创建诊断草稿。

## 3. 剪映版本预检

- Windows 下从安装注册表识别剪映版本和主程序。
- 自动 UI 导出在检测到 5.9 以后的未验证版本时默认停止。
- `--force-unsupported-version` 仅用于用户明确承担风险的尝试。

## 4. 媒体处理保真

- 标准化视频时默认保留原尺寸、横竖屏和帧率。
- 只对奇数尺寸、非 H.264 或非 `yuv420p` 等真正兼容性问题转码。
- 仅在显式传入目标宽高或帧率时改变视频规格。
- 缓存位于用户缓存目录，键包含源文件状态和转码参数。

## 5. Web-to-Video 格式正确性

- `.webm` 保留 Playwright 原始容器。
- `.mp4` 调用 FFmpeg 转为 H.264/yuv420p MP4，不再把 WebM 数据直接改名为 MP4。
- 不支持的扩展名或转码失败会返回失败，不宣称产物成功。

## 6. Windows Agent 终端稳定性

- 运行环境统一使用 UTF-8 并以替换策略处理无法编码的字符。
- 避免状态 Emoji 在 GBK 重定向终端中中断剪辑逻辑。

## 验收边界

- 单元测和静态检查只能证明 Python 逻辑、安全边界和草稿结构生成。
- 真实剪映视觉效果、新版 UI 自动化和实机导出需要单独人工验收。
- 本版不声称已适配所有未来剪映版本。
